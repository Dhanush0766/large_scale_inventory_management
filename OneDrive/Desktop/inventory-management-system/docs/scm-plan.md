# Software Configuration Management Plan

## Configuration Items

The following items are identified as configuration items in this project:

- Source Code (Frontend & Backend)
- Database Schema
- Documentation (SRS, Design)
- Test Cases
- Build Files

## Version Control Tool
GitHub is used to manage version control, track changes, and maintain history.

## Branching Strategy
- main → stable version
- develop → development branch
- feature/* → new features
- hotfix/* → bug fixes
