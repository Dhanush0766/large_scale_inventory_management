ABSTRACT

The IoT-Based Smart Checkers Automation System aims to bring a modern touch to the traditional game of checkers by combining the physical experience of playing on a real board with the power of Internet of Things (IoT) technology. In most cases, board games require players to be physically present, while online games remove the real-world interaction. This project bridges that gap by allowing players to play checkers remotely on a physical board that moves pieces automatically.

The system uses a Raspberry Pi as the main controller and an Arduino to handle hardware operations. Two stepper motors move the platform along the X and Y axes, while Hall sensors detect the positions of each piece. An electromagnet picks up and places the pieces on the correct squares. The Raspberry Pi processes the move commands received from an online interface and directs the hardware to replicate those moves on the actual board.

This setup creates a smooth link between digital gameplay and physical motion, making the checkers experience more interactive and engaging. The project successfully demonstrates accurate movement, reliable communication, and consistent performance. It opens the door for future improvements in smart gaming systems, educational models, and home automation applications.


CHAPTER 2 – INTRODUCTION
Background and Motivation

In today’s world, automation and the Internet of Things (IoT) have changed how people interact with technology. Games have also evolved — most are now played digitally, offering convenience but losing the physical feel of real-world play. Traditional checkers, on the other hand, needs both players to be in the same place, which limits how and when the game can be enjoyed.

The IoT-Based Smart Checkers Automation System aims to bring the best of both worlds together. It allows players to enjoy a real checkers board that moves the pieces automatically based on online gameplay. Using Raspberry Pi, Arduino, stepper motors, Hall sensors, and an electromagnet, the system makes every move visible and interactive on a physical board.

This project was inspired by the growing need for smart, connected systems that make everyday experiences more engaging and accessible. By merging IoT and automation, the Smart Checkers System shows how traditional activities can be reimagined through modern technology.


Overview of the Problem Domain

Traditional checkers games need both players to be in the same place, while online versions lack the real-world feel of moving actual pieces on a board. This gap between physical and digital gameplay inspired the idea of combining both experiences.

The main challenge is to design a system that can move checker pieces automatically and accurately based on online player inputs. This requires smooth coordination between hardware and software — including motors, sensors, and IoT communication.

The IoT-Based Smart Checkers Automation System solves this by using a Raspberry Pi and Arduino to control the movements through stepper motors, Hall sensors, and an electromagnet. This setup allows a real checkers board to reflect each online move in real time, creating an engaging and interactive playing experience.

Objectives of the Project

The main goal of this project is to create a smart checkers board that combines physical gameplay with online interaction. Through this system, players can experience the fun of a real board even when they are in different locations.

The specific objectives of the project are:

1.To build an IoT-based checkers board that moves pieces automatically based on player input.

2.To use Raspberry Pi and Arduino for communication, control, and hardware coordination.

3.To enable precise movement of pieces using stepper motors and an electromagnet.

4.To use Hall sensors for detecting and verifying the position of each piece.

5.To create a simple online interface that allows players to send and view moves in real time.

The Agile model was chosen because it allows flexibility and quick updates during development. 
In this project, both hardware and software had to be tested and adjusted several times — especially for motor movement, sensor readings, and IoT communication.

Agile made it easier to work in small steps, test each module, and make improvements right away based on results. It also helped the team manage tasks better and adapt quickly whenever any part of the system needed changes.

Conclusion and Future Enhancements :

Summary of Achievements :

The project “Effort Estimation Using Machine Learning: An Enhancement Over the Traditional COCOMO Model” successfully developed an intelligent system that improves the accuracy of software effort estimation.
By integrating machine learning algorithms such as Linear Regression, Random Forest, and Artificial Neural Networks (ANN) with the traditional COCOMO model, the system provides a more data-driven and adaptive approach to predicting project effort.

Key achievements include:
•	Automated and accurate prediction of software development effort.
•	Comparative analysis between traditional and ML-based estimation results.
•	Improved performance through preprocessing, feature selection, and algorithm tuning.
•	Development of a simple user interface for input and output visualization.
•	Validation of results using performance metrics like MAE, RMSE, and R².
 
The results demonstrate that machine learning methods can effectively enhance traditional estimation models, helping project managers make better cost and resource allocation decisions.

Limitations :
Despite its successful implementation, the project has certain limitations that restrict its scalability and adaptability:
1.	Dataset Dependency: The model’s accuracy is highly dependent on the quality and volume of the dataset used.
2.	Limited Dataset Variety: Only limited project types and datasets (e.g., NASA, COCOMO 81) were considered.
3.	Feature Limitation: The number of input parameters was restricted compared to real-world scenarios.
4.	Manual Retraining: The model requires manual retraining when new data are added.
5.	Scope Restriction: The project focuses primarily on effort estimation; cost and schedule estimations are not integrated yet.
Future Improvements:
To overcome the current limitations and make the system more powerful and practical, the following enhancements are suggested:
1.	Integration of Cost and Schedule Estimation: Extend the model to predict total cost and project duration alongside effort.
2.	Dataset Expansion: Include more diverse, industrial datasets to improve generalization and accuracy.
3.	Automated Retraining System: Implement continuous learning to update the model as new project data become available.
4.	Web-Based Dashboard: Deploy the system as a cloud-based web application for real-time estimation and accessibility.
5.	Deep Learning Integration: Use advanced models such as LSTM and Transformer architectures for complex project data.
